Configurer Google OAuth

Pour utiliser Google Drive depuis un fichier HTML local, il faut un Client ID Google gratuit. Ça prend 5 minutes.

1
Va sur console.cloud.google.com → crée un projet
2
Menu APIs & Services → Bibliothèque → active Google Drive API
3
Menu Identifiants → Créer des identifiants → ID client OAuth
4
Type : Application Web · Origines autorisées : null (pour fichier local) ou ton domaine
5
Copie le Client ID et colle-le dans le champ Clé API, puis clique Connecter
